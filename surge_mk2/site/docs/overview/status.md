# 検証状況

どの機能が実車で確かめられていて、どれがまだ計算上の値なのかを一覧にします。
**ほかのページの数値を使う前に、ここで該当の行を確認してください。**

!!! warning "この表の出どころ"
    根拠は、ファーム側の [`CLAUDE.md`][fw-claude]（「現在の状態」）、上位側の [`PROGRESS.md`][progress]
    （開発記録）、ソースコード中のコメントです。**これらは開発者本人の記録であり、第三者による再現確認ではありません。**
    記録が無いものは「確認できず」と書き、「未検証」とは区別しています。

凡例: 【実機確認】【シム／ホスト検証】【未検証】【確認できず】

## 計測で得た車両パラメータ

[`vehicle.toml`][vehicle-toml] の `[dynamics]` は 2026-09-28 に実機で同定した値です。ただし同定した後に
ファームの制御が変わっているので、変更後に測り直していない項目は古い可能性があります
（`vehicle.toml` 自身が「ファームの ABS・TC・TV を変えたら②（TV なら①③も）を測り直すこと」と注記しています）。

| 量 | 値 | 注記 |
|---|---|---|
| 横方向グリップ `mu` | 約 0.42（`[dynamics]`）／約 0.51（`[control.plant]`） | **同じファイル内で 2 つの値が異なる**。前者は旋回試験の限界から、後者はタイヤモデルのフィット。コースの走行では 5〜5.5 m/s² でも外れなかったので、前者は低めの可能性がある（`vehicle.toml` のコメント） |
| 車体の利得 | 約 21.5 (m/s²)/(N·m) | 名目値 `1/(車輪半径×質量)` = 16.7 より大きい |
| 転がり抵抗の減速度 | 約 0.27 m/s² | |

# 検証状況

どの機能が実車で確かめられていて、どれがまだ計算上の値なのかを一覧にします。
**ほかのページの数値を使う前に、ここで該当の行を確認してください。**

!!! warning "この表の出どころ"
    根拠は、ファーム側の [`CLAUDE.md`][fw-claude]（「現在の状態」）、上位側の [`PROGRESS.md`][progress]
    （開発記録）、ソースコード中のコメントです。**これらは開発者本人の記録であり、第三者による再現確認ではありません。**
    記録が無いものは「確認できず」と書き、「未検証」とは区別しています。

凡例: 【実機確認】【シム／ホスト検証】【未検証】【確認できず】

## 計測で得た車両パラメータ

[`vehicle.toml`][vehicle-toml] の値は、2026-10-18 に作り直した車両の校正（`docs/calibration.md`）で測り直す途中です。
前輪エンコーダ（校正 1）と遅延（校正 4）は 2026-10-18 の記録の値、ほかは 2026-09-28 の旧同定の値です。

| 量 | 値 | 注記 |
|---|---|---|
| 横の上限（`[limits] a_lat_m_s2`） | 約 4.1 m/s² | 旧旋回試験の値（μ 0.42）。走行中の学習の初期値。コースの走行では 5〜5.5 m/s² でも外れなかったので低めの可能性がある |
| 車体の利得 | 約 21.5 (m/s²)/(N·m) | **旧解析の誤り**。同じ記録を PI を仮定せずに当てはめ直すと 16.5〜16.8（名目 16.7）。校正 5 で測り直す |
| 転がり抵抗の減速度 | 約 0.27 m/s² | |
